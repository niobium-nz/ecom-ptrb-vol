# Generated Project Agent Roles

The coordinator owns integration and final acceptance. Delegate bounded work to these roles when native sub-agents are available; otherwise execute them sequentially with the same handoff record.

## Platform And Dependencies
Owns current stable caret dependency ranges, exact lockfile resolutions, reviewed install scripts, lockfile/engine health, self-contained project paths, Next.js/Tailwind/TypeScript/ESLint configuration, environment parsing, `allowedDevOrigins`, and a clean `.vscode/launch.json` with application-only source-map resolution.

## Customer Experience
Owns customer-facing copy, narrow-phone heading/readability checks, mandatory testimonials, applied-coupon clarity, em-dash prohibition, and built-HTML content verification.

## Brand Assets
Owns the design-token application and SVG-source-to-transparent-PNG logo pipeline. White source pixels become transparent; black source marks become the selected theme color. Shopper-facing code must not render the source SVG.

## Commerce And Checkout
Owns required integer-cent default offer prices, background landing quotes, live-quote checkout, raw `Response` parsing, cent-safe monetary handling, localized fields, numeric `shippingId`, store/notification endpoint routing, neutral tracked/ETA copy, Stripe Payment Element, order creation, subscription, contact, tracking, order status, shared return-home navigation, and checkout analytics including `OfferSelect`.

## Quality And Runtime
Owns Vitest/Testing Library, Playwright, 100% coverage thresholds for testable production code, raw-Response/status/body regression tests, cent/default-price tests, clickable return-home tests, browser error listeners, warning-free LAN/local dev smoke checks, and regression tests for every discovered defect.

## Deployment
Owns test/prod GitHub workflows, Cloudflare Pages provisioning/deploy, custom domain/DNS, environment separation, and deploy-secret isolation.

## Required Handoff
Each role reports files changed, decisions, unresolved blockers, tests added, commands run, exact results, and risks. No role claims another role's checks passed without evidence.

## Final Gate
Do not complete or deploy while dependency/install-script warnings, external project paths, lint/type errors, incomplete coverage, failed tests, mobile/content/browser/runtime warnings, build failures, unparsed vendor Responses, major-unit misuse of cent amounts, missing return-home navigation, prohibited fulfillment-origin copy, raw SVG logo usage, or string-valued vendor `shippingId` remain.
